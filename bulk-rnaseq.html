A complete training module covering the RNA-seq pipeline, from raw reads to biological insight.

Back to modules
Overview

This module walks through a complete workflow, taking raw sequencing data all the way to interpretable, biologically meaningful results.

Pipeline Steps
  • Quality Control: assess raw read quality.
  • Read Trimming: remove adapters and low-quality bases.
  • Alignment: map reads to the reference genome.
  • Quantification: count reads per gene.
  • Differential Expression: identify changes across conditions.
  • Functional Enrichment: interpret results biologically.
