Bulk RNA-seq Analysis Module

Overview

This module covers the complete Bulk RNA-seq analysis pipeline, including quality control, alignment, quantification, differential expression, and downstream functional analysis.

Topics Covered

  • Raw data quality control (FastQC)
  • Read trimming (Trimmomatic / fastp)
  • Alignment (STAR / HISAT2)
  • Quantification (featureCounts / Salmon)
  • Differential expression (DESeq2 / limma)
  • Functional enrichment (GO / KEGG / GSEA)
